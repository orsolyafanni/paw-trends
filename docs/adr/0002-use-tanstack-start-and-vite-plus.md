# Use TanStack Start and Vite+ for the web app

Paw Trends will use React and TypeScript in TanStack Start's client-only SPA mode, shadcn interface components, Vite+, and Ultracite's type-aware Oxlint and Oxfmt presets for core, React, TanStack, and Vitest. This deliberately accepts pre-1.0 framework and toolchain risk in a study project to gain typed routing and one integrated development, formatting, linting, testing, and build workflow; ChatGPT Sites will host the static application.
